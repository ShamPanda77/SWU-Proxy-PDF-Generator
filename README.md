# SWU Proxy PDF Generator

**SWU Proxy PDF Generator** est un outil non officiel destiné à faciliter la préparation et la génération de PDF proxy pour *Star Wars Unlimited*.

## Version actuelle

**1.1.0**

## Fonctionnalités

- Sélection de cartes par extension.
- Génération de PDF prêts à imprimer.
- Gestion des leaders, bases et cartes.
- Import de decks depuis une URL publique SWUDB.
- Import de decks depuis des données JSON.
- Import de decks au format Melee.
- Import de decks au format Picklist.
- Import depuis le presse-papier.
- Import depuis un fichier.
- Glisser-déposer de fichiers JSON/TXT.
- Sélection automatique de la version Standard lors de l'import d'une Picklist.
- Mise à jour automatique des extensions disponibles.
- Interface multilingue.
- Génération et téléchargement des images nécessaires.
